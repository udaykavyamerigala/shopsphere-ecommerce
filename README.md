# ShopSphere - E-Commerce Homepage

ShopSphere is an Amazon-inspired responsive e-commerce homepage developed as part of a Frontend UI Replication Assignment.

The project recreates common e-commerce interface patterns using original HTML, CSS and JavaScript code.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Flexbox
- CSS Grid
- Responsive Web Design

## Features

- Responsive e-commerce homepage
- Header with brand and delivery location
- Product search
- Search by category
- Navigation menu
- Hero promotional slider
- Product categories
- 14 product cards
- Product ratings
- Current and original prices
- Discount percentage
- Add to Cart functionality
- Dynamic cart item counter
- Product category filtering
- Product sorting
- Mobile navigation menu
- Responsive desktop, tablet and mobile layouts
- Structured footer
- Back to top functionality

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional installation is required.

## Project Structure

ShopSphere-Ecommerce/

- index.html
- style.css
- script.js
- README.md

## Challenges Faced

One of the main challenges was creating a responsive layout that works properly across desktop, tablet and mobile screen sizes.

Another challenge was implementing multiple JavaScript features such as product search, category filtering, sorting, cart updates and the hero slider while keeping the code organized.

These challenges were solved using CSS media queries, Flexbox, CSS Grid, JavaScript array methods and DOM manipulation.
